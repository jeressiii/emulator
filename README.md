# emulatorVFS
**emulatorVFS** - это эмулятор виртуальной файловой системы, работающий полностью в оперативной памяти. Проект реализует основные команды файловой системы в изолированной среде без модификации реальной файловой системы пользователя.

## Особенности

### Основные команды файловой системы
- ls - список файлов (поддержка -l)
- cd - смена директории  
- pwd - текущий путь
- date - вывод текущей даты
- tail - вывод последних строк (поддержка -n)
- find - поиск файлов
- chmod - смена параметров доступа для пользователей
- mkdir - создание директории
- touch - создание файла
- exit - выход

При вводе **test**, запускает тестовый файл, который проверяет работу каждой из команд.

## Технологии
- Python 3.13.2 - основной язык
- shlex - парсинг команд
- fnmatch - сравнение имен файлов по шаблонам
- pathlib.Path - работает с реальной файловой системой через
