# emulatorVFS
**emulatorVFS** - это эмулятор виртуальной файловой системы, работающий полностью в оперативной памяти. Проект реализует основные команды файловой системы в изолированной среде без модификации реальной файловой системы пользователя.
Доступные команды: ls, cd, pwd, mkdir, touch, chmod, tail, date, find, test, exit.
При вводе **test**, запускает тестовый файл, который проверяет работу каждой из команд.
